# 登记交换服务
运行 python3 -m lab.provider --port 8765。GET /view 返回冻结 epoch、revision、ceiling；GET /summary 与 /bundle 均要求 epoch、revision、lower、upper 查询参数，范围闭区间。摘要是现有 feeds.bundle.segments 的 canonical 二元组摘要，事件包使用原生 bundle 格式。POST /control 接收 {"expire":true}，使旧 revision 返回 410。数据为 32 条独立资产登记，序号与摘要可直接复核。服务仅模拟只读远端，不操作本地台账。
